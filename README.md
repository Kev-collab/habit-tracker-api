# Habit Tracker API

Proyecto correspondiente al setup inicial de una aplicación web para gestión de hábitos, desarrollado con Express.js y MongoDB Atlas.

## Tecnologías utilizadas

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Cors
- Dotenv
- Nodemon
